# Linux Command-Line Fundamentals

A collection of hands-on Linux exercises demonstrating foundational command-line skills, including terminal navigation, file and directory management, and text editing with GNU Nano.

## Exercises

### 1. [Navigating the Terminal](01-terminal-navigation/README.md)
Navigated the Linux file system, listed directory contents, and accessed command documentation using terminal commands.

### 2. [Making Files and Folders](02-files-and-directories/README.md)
Created files, directories, and nested directory structures using Linux commands such as `touch` and `mkdir`.

### 3. [GNU Nano Text Editor](03-gnu-nano/README.md)
Used GNU Nano to open and modify files, search and replace text, navigate to specific lines, save changes, and insert content from other files.

### 4. [Deleting, Moving, & Copying](04-file-management/README.md)

Deleted, moved, renamed, and copied files and directories using `rm`, `mv`, and `cp`, while exploring Bash features such as brace expansion and conditional command execution to improve efficiency.

## Skills Demonstrated

- Linux command-line navigation
- File and directory management
- Terminal-based text editing
- Command-line documentation and help resources
- Recursive file and directory operations
- Bash brace expansion and conditional command execution

## Learning Resource

Exercises completed as part of Colt Steele's Udemy course, *The Linux Command Line Bootcamp: Beginner to Power User*.
